Política de privacidad

Última actualización: 10 de agosto de 2026

Esta política explica cómo Impacto accede, utiliza y protege los datos necesarios para generar sugerencias de conversación, análisis de capturas y funciones personalizadas.

Datos que tratamos

  • Identidad técnica anónima: un identificador aleatorio, tokens de sesión, cuota, racha, referidos y estado de suscripción. No pedimos nombre, correo ni contraseña para usar la app.
  • Contenido que eliges enviar: capturas, mensajes, contexto adicional, perfil de escritura y preferencias. Se utiliza para producir el resultado solicitado.
  • Reportes: si marcas una respuesta, conservamos el texto generado, el motivo y datos técnicos mínimos para moderación y mejora de seguridad.
  • Datos locales: preferencias, perfiles e historial se guardan en tu dispositivo. Las capturas no se incorporan al historial local.

Cómo utilizamos los datos

Los usamos exclusivamente para prestar las funciones solicitadas, personalizar respuestas, administrar límites y suscripciones, prevenir abuso, mantener seguridad y atender reportes. No vendemos datos ni los utilizamos para publicidad dirigida.

Procesamiento de IA y proveedores

Las solicitudes se transmiten cifradas mediante HTTPS a infraestructura de Supabase y, para generar resultados, a OpenAI, que actúan como proveedores de servicio. Cuando se habiliten compras, Google Play y RevenueCat procesarán la información necesaria de la suscripción. Cada proveedor aplica sus propios controles y obligaciones de seguridad.

Capturas y conservación

Impacto no guarda las capturas ni el contenido completo de las conversaciones en su base de datos después de completar la solicitud. Los proveedores pueden conservar registros operativos o de seguridad conforme a sus políticas. Los datos de cuota, referidos y suscripción se mantienen mientras exista la identidad anónima. Los reportes se conservan mientras sean necesarios para revisión y cumplimiento.

Teclado Impacto

Al activarlo, Android permite que el teclado lea el texto del campo activo. Impacto lo muestra localmente como borrador y no lo transmite al servidor desde el teclado. Las últimas sugerencias generadas se guardan localmente para insertarlas cuando tú las elijas. Evita utilizar teclados de terceros en campos con contraseñas o información especialmente sensible.

Seguridad

Los datos enviados fuera del dispositivo viajan cifrados mediante HTTPS/TLS. Aplicamos control de acceso, sesiones autenticadas anónimas y límites de entrada. Ningún sistema es infalible; recomendamos no subir información que no sea necesaria para recibir el análisis.

Tus controles

Puedes borrar el historial y los perfiles locales desde Ajustes. También puedes eliminar la identidad anónima y sus datos asociados desde la app o usar la página de eliminación si ya no tienes acceso al dispositivo.

Edad

Impacto está dirigido a personas mayores de 18 años y no está diseñado para niños. No recopilamos intencionalmente datos de menores.
